# Contributing

Run `python -m unittest discover -v` from a source checkout with Python 3.12+. Native tests require an authorized ordinary local directory, with usable ancestor handles. Keep original-byte fixtures synthetic and reproducible. Use `python fixtures/build_fixtures.py --output fixtures/generated` to regenerate the ZIP matrix.

Report bugs with a synthetic ZIP, exact policy/runtime versions and safe diagnostics. Review filenames in reports before sharing. Do not upload real user archives, local roots, credentials, environments or generated personal reports.

Preserve the single authority in `model.py`, strict imported-plan revalidation and native fail-closed ownership checks. Browser editing exports drafts; it must not implement platform rules or claim validation. Add a regression that first fails for the observed behavior. Host/CI configuration alone is not native execution evidence.
